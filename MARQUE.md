# Usage du nom et du logo Cotutelle

Le code de Cotutelle est libre. Son nom et son logo désignent, eux, le projet
officiel publié sur <https://github.com/Dwoinn/cotutelle>. Cette page dit ce
que vous pouvez en faire. Elle n'est pas une licence de marque : elle décrit
l'usage que les auteurs acceptent.

## Ce qui est permis sans demander

- Dire que votre projet est « basé sur Cotutelle », « compatible avec
  Cotutelle » ou « un fork de Cotutelle ». L'attribution « Basé sur
  Cotutelle » est d'ailleurs obligatoire (voir [NOTICE.md](NOTICE.md)).
- Utiliser le nom pour parler du projet : articles, tutoriels, comparatifs.
- Distribuer ou héberger la version officielle **non modifiée** sous le nom
  Cotutelle, y compris contre paiement.

## Ce qui ne l'est pas

- Distribuer ou héberger une version **modifiée** sous le nom « Cotutelle »
  ou sous un nom qui prête à confusion. Choisissez un autre nom et un autre
  logo, et créditez le projet d'origine.
- Laisser entendre que votre version, votre service ou votre entreprise est
  le projet officiel, ou qu'il est approuvé par ses auteurs.

## Pourquoi

Cotutelle s'installe avec les droits d'administration sur l'ordinateur
d'enfants. Une famille qui lit « Cotutelle » doit pouvoir compter sur le fait
qu'il s'agit bien du code publié ici.

Pour tout autre usage, ouvrez une discussion sur le dépôt.
